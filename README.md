# GRASPS 설계 도우미

과학과 성취기준에서 백워드 설계(UbD) Stage 1을 먼저 확정한 뒤, 그 이해를 평가하는 GRASPS 수행과제와 루브릭 초안을 만드는 웹앱입니다.

- 바로 쓰기: **https://yurowa90.github.io/UbD/**

## 누구를 위한 도구인가

수행평가 과제를 설계하는 과학 교사를 위한 도구입니다. 성취기준에서 GRASPS 과제를 곧바로 뽑으면 "무엇을 이해했다는 증거인가"가 빠진 활동 중심 과제가 되기 쉽습니다. 이 앱은 영속적 이해와 본질적 질문을 먼저 정하고, 과제와 루브릭이 그 이해에 맞춰져 있는지 확인하도록 순서를 잡아 둡니다.

## 무엇을 하나

4단계로 진행합니다.

1. **입력** — 2022 개정 교육과정 과학과 공식 성취기준 473개(초·중·고 22과목)에서 학교급 → 과목 → 영역 → 성취기준 순으로 고릅니다. 직접 입력 모드도 있습니다. 공식 성취수준(A~E)이 있는 371개 기준을 고르면 그 서술이 루브릭 눈금의 근거가 됩니다.
2. **Stage 1 검토** — 전이 목표, 영속적 이해 2개, 본질적 질문 2개가 생성됩니다. 교사가 검토하고 필요하면 고칩니다. 이 단계는 건너뛸 수 없습니다.
3. **번들 선택** — 6요소(목표·역할·청중·상황·산출물·기준)가 서로 맞물린 GRASPS 과제 세트 3개가 나옵니다. 세 세트는 청중이 학급·학년 내부, 학교·지역사회, 전문가·공적 기관으로 서로 다릅니다. 하나를 고릅니다.
4. **완성** — 요소별로 잠그거나 다시 생성할 수 있습니다. 한 요소를 바꾸면 그 요소에 기대는 다른 요소는 '갱신 필요'로 표시됩니다. 고른 세트는 별도의 정합성 감사를 거치며, 감사에 실패한 항목이나 갱신이 필요한 요소가 남아 있으면 내보내기가 잠깁니다.

그 밖의 기능

- **정렬 표식**: 영속적 이해마다 색 표식(U1, U2…)이 붙고, 그 이해를 평가하는 루브릭 준거에도 같은 표식이 붙습니다.
- **공식 성취수준 맞춤**: 성취수준이 있는 기준이면 루브릭 수준을 A~E(과학탐구실험은 A~C) 체계에 맞춥니다.
- **UDL 산출물 옵션**: 켜면 같은 이해를 보고서·발표·영상·모형 등 여러 형태로 드러내도록 산출물을 다양화합니다(UDL 3.0).
- **내보내기**: PDF(브라우저 인쇄), 엑셀 .xlsx(개요·GRASPS·루브릭 3시트), Markdown(복사·다운로드).

## 사용 방법

1. 위 주소를 엽니다.
2. 오른쪽 위 **API 키 설정**에서 Google Gemini API 키를 등록합니다.
   - 키는 [Google AI Studio](https://aistudio.google.com/app/apikey)에서 발급받습니다.
   - 키는 이 브라우저의 localStorage에만 저장되고, 앱은 브라우저에서 Google API로 직접 요청합니다. 별도 서버로 보내지 않습니다.
   - 같은 창에서 모델을 고를 수 있습니다(기본 Gemini 2.5 Flash). 고른 모델을 키가 지원하지 않으면 지원되는 모델로 자동 대체됩니다.
3. 성취기준을 고르고 단계를 따라 진행합니다.

## 내 컴퓨터에서 실행하기

Node.js와 npm이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:5173
```

## 한계

- Gemini API 키가 있어야 생성 기능을 쓸 수 있습니다. 요청 한도를 넘으면(429) 잠시 뒤 다시 시도해야 합니다.
- 생성 결과는 교사가 검토하고 고쳐 쓰는 초안입니다.
- 내장 성취기준 목록은 2022 개정 교육과정 과학과만 들어 있습니다.

## 근거 자료

`src/knowledge/`의 지식 파일은 아래 원자료를 요약한 것이며, 각 파일에 1차 출처와 쪽·그림 번호를 적었습니다.

- McTighe, J. & Wiggins, G. (2012). *Understanding by Design® Framework* [백서]. ASCD. — Stage 1 판별 기준, 이해의 여섯 측면, 품질 점검표, Stage 2 원리.
- Wiggins, G. & McTighe, J. (2005). *Understanding by Design* (Expanded 2nd ed.), 7장 pp. 157–159, Figure 7.7 "GRASPS Task Design Prompts". ASCD. — GRASPS 6요소 약어의 1차 출처(2012 백서에는 이 약어가 나오지 않습니다).
- CAST (2024). *UDL Guidelines version 3.0.* https://udlguidelines.cast.org — UDL 산출물 옵션.

원문 인용이 필요하면 각 원자료를 직접 확인하세요.
